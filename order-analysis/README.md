# Order Analysis

A Python project that analyzes order data from a CSV file and visualizes monthly trends using pandas, NumPy and Matplotlib.

## What it does

- Loads order data from orders.csv
- Cleans and processes the data with pandas
- Groups results by month (Jan to Dec) in calendar order
- Formats numbers cleanly (for example, 2000.0 is shown as 2000)
- Plots the results as charts with Matplotlib

## Tech stack

- Python 3
- pandas
- NumPy
- Matplotlib

## How to run

1. Clone the repository:
   
   git clone https://github.com/ayush-srivas/basic-python-project.git
   cd basic-python-project/order-analysis
   
2. Install the libraries:
   
   pip install pandas numpy matplotlib
   
3. Run the script (the quotes are needed because of the space in the filename):
   
   python "one .py"
